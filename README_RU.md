# Аналитический SQL-пайплайн когортного анализа

Пайплайн для анализа продуктовых метрик на SQLite и Python (SQLAlchemy, Pandas). Рассчитывает удержание когорт, динамику решения задач и финансовые показатели на основе связанных реляционных таблиц.

---

## Описание проекта

Запрос объединяет 4 таблицы (`users`, `codesubmit`, `transaction`, `language`) в единый помесячный когортный отчет.

Основные задачи:
- Расчет доли активных пользователей по месяцам регистрации
- Подсчет общего числа попыток и успешных решений задач
- Расчет помесячной выручки и нарастающего максимума
- Динамическое выделение топ-5% лучших программистов по каждому языку (через `PERCENT_RANK`)
- Фильтрация когорт с положительным помесячным ростом выручки (через `LAG`)

---

## Архитектура SQL-запроса (8 CTE)

Логика разбита на 8 изолированных шагов (Common Table Expressions):

1. **`us_agg`**: Считает долю активных пользователей по месяцу регистрации (`date_joined`).
2. **`codesubmit_per_month`**: Считает общее и успешное количество сабмитов по месяцам.
3. **`month_revenue`**: Считает месячную выручку и нарастающий максимум через `MAX(SUM(...)) OVER (ORDER BY ...)`.
4. **`code_lang`**: Агрегирует попытки и успешные решения пользователей по языкам программирования.
5. **`five_perc_prep`**: Рассчитывает перцентиль каждого пользователя внутри его языка через `PERCENT_RANK()`.
6. **`five_perc`**: Находит пороговое значение 95-го перцентиля (граница топ-5%).
7. **`top5per_us`**: Собирает список ID лучших программистов через запятую (`GROUP_CONCAT`).
8. **`for_last`**: Объединяет все витрины и подтягивает выручку за предыдущий месяц через `LAG()`.

Итоговый `SELECT` отсекает когорты, у которых выручка оказалась ниже или равна предыдущему месяцу.
