# Продвинутый SQL: Модульный когортный пайплайн с оконными функциями

[English Version](README.md) | [Русская версия](README_RU.md)

### Описание проекта
Аналитический SQL-пайплайн на SQLite и Python (SQLAlchemy, Pandas) для комплексной оценки удержания пользователей, успешности решения задач и динамики выручки по когортам

Запрос объединяет и анализирует четыре реляционные таблицы (`users`, `codesubmit`, `transaction`, `language`) в единый сводный когортный отчет

Решаемые задачи:
* Доля активных пользователей в разрезе месяцев регистрации
* Соотношение общего числа отправок кода к успешным решениям
* Расчет накопительного максимума выручки
* Динамическое выделение топ-5% программистов по каждому языку (через `PERCENT_RANK`)
* Фильтрация когорт с помесячным ростом выручки (через `LAG`)

---

### Архитектура SQL-пайплайна

Логика запроса декомпозирована на 8 модульных CTE (Common Table Expressions):

1. **`us_agg`**: Расчет доли активных пользователей с группировкой по дате регистрации (`date_joined`)
2. **`codesubmit_per_month`**: Подсчет общего количества попыток и успешных решений за месяц
3. **`month_revenue`**: Расчет помесячной выручки и скользящего максимума через `MAX(SUM(...)) OVER (ORDER BY ...)`
4. **`code_lang`**: Агрегация попыток и успешных решений по языкам программирования и месяцам
5. **`five_perc_prep`**: Расчет перцентилей для каждого разработчика внутри его языка через `PERCENT_RANK()`
6. **`five_perc`**: Определение границы 95-го перцентиля (порог отсечения топ-5%)
7. **`top5per_us`**: Склейка ID лучших пользователей в строку через запятую с помощью `GROUP_CONCAT`
8. **`for_last`**: Объединение всех CTE и выгрузка выручки предыдущего месяца через `LAG()`

Итоговый `SELECT` оставляет только те когорты, которые показали реальный рост выручки относительно предыдущего месяца
